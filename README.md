# CharInspectPlus

[![Last commit](https://img.shields.io/github/last-commit/Kkthnx-Wow/CharInspectPlus)](https://github.com/Kkthnx-Wow/CharInspectPlus/commits/main)
[![CurseForge](https://img.shields.io/badge/CurseForge-Download-orange)](https://www.curseforge.com/wow/addons/charinspectplus)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

CharInspectPlus is a clean, set-and-forget reskin of the Character and Inspect frames.

## What it does

- Expands the character model to fill the frame and strips the default clutter.
- Resizes every equipment slot to a uniform size for a tidier layout.
- Drops in a class-themed dressing-room backdrop on the Paper Doll tab.
- Covers both your Character frame and the Inspect frame when you check other players.
- Runs with zero configuration and stays safe in combat.

## Get it

Install from [CurseForge](https://www.curseforge.com/wow/addons/charinspectplus), or grab the zip from the [Releases page](https://github.com/Kkthnx-Wow/CharInspectPlus/releases).

## Quick start

1. Install CharInspectPlus via CurseForge, or extract it into `World of Warcraft\_retail_\Interface\AddOns`.
2. Restart WoW (or `/reload` if already in game).
3. Open your Character frame with `C`, or inspect another player. The new layout applies itself.
